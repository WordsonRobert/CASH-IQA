# figures/

These figures are generated by `03_analysis/make_figures.py` from `results/tables/` (and, for fig. 1,
`results/stage1_automl/`). Each one exists as a `.pdf` for the paper and a `.png` for viewing.

| Figure | Shows | Source table |
|---|---|---|
| `fig1_paired_gain_over_ridge` | per-split SROCC gain of `tpe_hb` over `ridge_concat`, nested and holdout | stage-1 JSON |
| `fig2_anytime_curves` | test SROCC of the incumbent against budget share, for the 4 strategies × 6 datasets | `automl_anytime.csv` |
| `fig3_family_selection` | family selected per split: local on synthetic sets, global on authentic sets | `family_selection_counts.csv` |
| `fig4_shapley_fusion_gain` | exact Shapley share of the fusion gain, encoders × datasets | `shapley_gain.csv`, `shapley_baseline.csv` |
| `fig5_shapley_interactions` | pairwise interaction matrices, synthetic vs authentic | `shapley_interactions_gain.csv` |
| `fig6_cross_dataset_matrices` | source × target SROCC: full CASH, global + equal weights, ridge | `cross_transfer.csv` |
| `fig7_transfer_decomposition` | mean cross-dataset SROCC per variant and domain pair | `cross_transfer.csv` |
| `fig8_per_distortion` | within-type SROCC per distortion on KADID-10k and TID2013 (< 0.75 highlighted) | `per_distortion.csv` |
| `fig9_encoder_weights` | effective fusion weight w_e² / Σ w² per dataset | `encoder_weights.csv` |
